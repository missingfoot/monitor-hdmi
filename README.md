# monitor-hdmi

Switches the ASUS MX279 monitor to this PC's HDMI input. Adds an "HDMI 1" or
"HDMI 2" launcher and binds it to Meta+H.

## Install

```
gh repo clone missingfoot/monitor-hdmi && cd monitor-hdmi
./install 1        # or ./install 2 — the input this PC is plugged into
```

Then log out and back in.
